# Cluster CAN0 protocol (proposal)

Generated by `can_protocol.py`; do not edit by hand.

Classic CAN, 11-bit IDs, 500 kbit/s (proposed), little-endian. Nodes: **ECU** (ecu-pcb), **GAUGES** (gauges/, S32K144), **DISPLAY** (display/, Android). Only `0x100` exists in firmware today (placeholder in `ecu-firmware`).

**Value policy.** DISPLAY aggregates: per small gauge it prefers a fresh ECU value (< 500 ms old), else GAUGES' local sender reading, and commands GAUGES on `0x400`. If DISPLAY's heartbeat `0x4F0` is silent for 1500 ms, GAUGES renders standalone with the same ECU-then-local rule.

| ID | Name | Sender | Period | DLC |
|---|---|---|---|---|
| 0x100 | EcuState | ECU | 100 ms | 1 |
| 0x200 | EcuEngine | ECU | 50 ms | 7 |
| 0x201 | EcuVehicle | ECU | 100 ms | 7 |
| 0x300 | GaugesSense | GAUGES | 100 ms | 8 |
| 0x301 | GaugesStatus | GAUGES | 1000 ms | 4 |
| 0x400 | DisplayGauges | DISPLAY | 50 ms | 8 |
| 0x401 | DisplayState | DISPLAY | 100 ms | 3 |
| 0x4F0 | DisplayHeartbeat | DISPLAY | 1000 ms | 2 |
